# Security

Report vulnerabilities privately through GitHub's "Report a vulnerability"
(private security advisory) on this repository. Do not open a public issue.

guarded-update changes and restarts software unattended, so reports about the
following are especially welcome:

- secret values reaching logs, reports, or the model prompt;
- release-note content that changes what gets installed;
- any path that runs commands with elevated privileges.

Best effort, no warranty.
